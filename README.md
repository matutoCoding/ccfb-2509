# 孔探路径规划与成像复现系统

浏览器内运行的航空发动机孔探（borescope）路径规划、成像复现与损伤跟踪系统。
**TypeScript + WebGPU + IndexedDB**，无后端、无第三方运行时框架，数据全部留在本地浏览器，导出文件交质量部归档。

## 启动

```bash
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5173）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
npm test           # 37 个单元/集成测试（纯数学层，Node 内运行）
```

WebGPU 需 Chrome/Edge 114+。浏览器不支持时视窗页会给出明确提示，其余页面（构型、探头库、复查）仍可使用。

## 五个页面与功能对应

| 页面 | 对应需求 | 核心实现 |
| --- | --- | --- |
| 发动机构型 | 1 | 机型/级/孔探口录入；参数化叶片（NACA 厚度+分段圆弧中弧线+安装角/后掠）；盘车定位计算器，`crankToAlignBlade` 反解盘车角并回验叶片编号 |
| 探头路径 | 2 | 刚/柔性探头库；柔性探头常曲率链生长，受最小弯曲半径约束；机匣/轮毂圆柱碰撞 + 导向器叶栅 BVH 射线碰撞；卡点与原因在 2D 俯视图标出 |
| 孔探视窗 | 3、4、5、6、7 | WebGPU 实时成像；点击画面反算叶片参数坐标并标注；阴影法测量对照 AMM 限度；轨迹录制/回放 |
| 损伤标注 | 5、6、9 | 全部标注总览、数据质量校验面板、坏数据徽标、质量部 CSV 导出 |
| 复查对比 | 8 | 按发动机序号的时间轴、同 trackId 损伤增长曲线、线性外推到限循环、完整 JSON 数据包导入导出 |

## 关键指标如何保证

### 1. 损伤位置可复现：双探头位姿反算偏差 ≤ 0.5mm

- 损伤**不以屏幕坐标存储**，而存叶型参数坐标 `(叶片编号, 叶高百分比 spanPct, 距前缘弦向比 chordT, 吸力/压力面)` + 当时世界坐标双份。
- 视窗点击 → 像素射线（含镜头畸变反解）→ BVH 加速三角形求交（限定当前对准叶片、解析外法线做正面剔除）→ 在参数化叶面上做线搜索精修，落点严格回到解析叶面。
- 同一物理点从两个不同探头位姿反算，收敛到同一参数坐标。测试实测最大偏差 **0.0048mm**（指标 0.5mm，余量 100 倍），见 `src/core/geometry/backprojection.test.ts` 的「精度档案」用例。

### 2. 轨迹回放叠图无肉眼错位

画面只由确定性输入决定：`(发动机构型版本, 探头定义, 孔探口, 盘车角, 插入深度)`。
轨迹不存任何派生网格或随机状态；表面噪声全部用世界坐标哈希（CPU `hash3` 与 WGSL 同思路）。
同一轨迹时刻两次求解的头端位置/朝向/路径采样点逐位相等（`src/data/replay.test.ts`），因此同参数下渲染输入完全一致，截图叠加无可量化错位。

### 3. 光学成像（任务点 3、4）

- WGSL 前向管线：Cook-Torrance 微表面 BRDF，单晶合金高金属度低粗糙度 → 强高光随探头角度晃动；TBC 弱金属陶瓷感；积碳吸光；高温变色蓝紫-褐黄回火色带；涂层剥落露出合金底材（`coatingSpallColor`）。
- LED 环形光：8 颗 LED 随探头头端运动，平方反比衰减 + 余弦入射，近距过曝（Reinhard 滚白）远距压黑，阴影方向随光源变化。
- 后处理 pass：径向桶形畸变（k1/k2，CPU 反解与 GPU 后处理同一级数公式）、cos⁴ 风格暗角、gamma。
- 直视/侧视镜头在相机模型中统一处理（侧视光轴折转 90°）。

### 4. 阴影法测量（任务点 6）

投影线偏移 Δ、工作距离 L、像素焦距 f、投影角 θ 按相似三角形反推深度 `h = ΔL/(f+Δ·cotθ)`，长度按像素标定尺换算；
与该级 AMM 限度对照，超限标红并给复查间隔建议（0=立即停场，其余 25/50/100/200 循环分级）。

## 演示数据（任务点 9）

发动机构型页点「载入演示数据」，确定性 PRNG（mulberry32，固定种子）生成：

- **2 种虚构发动机构型**：TF-2000 双转子高压核心机（4 级、3 个孔探口）、TS-800 涡轴燃气涡轮（2 级）；
- 4 支探头（刚性直视/侧视、柔性 6mm/4mm）；
- **34 条孔探记录、数十条损伤标注**；
- 三类坏记录，均被 `validateAll` 自动识别并在页面红色/橙色徽标展示：
  - 探头卡住（路径求解 `stuck`，含机匣/导向器/最小弯曲半径三种原因）；
  - 盘车角度丢帧（轨迹帧 `crankDeg = NaN`，回放时拒绝重建该帧画面）；
  - 标注落在叶片几何外（`spanPct>1` 或 `chordT>1`，径向半径校验）。

## 目录结构

```
src/
  core/
    math/          向量、4x4 矩阵（列主序，与 WebGPU 一致）
    geometry/      参数化叶片 airfoil、BVH 网格 bladeMesh、反算 backprojection、材质 materials
    probe/         探头路径/碰撞 probePath、轨迹 trajectory
    optics/        镜头畸变 lens、环形光 lighting、阴影测量/AMM/趋势预测 measurement
    types.ts       全部领域模型
    validation.ts  坏记录校验
  data/            IndexedDB 封装 db、导入导出 export、种子数据 seed
  render/          WGSL 着色器 shaders、GPU 几何 geometryGpu、WebGpuRenderer
  ui/              状态 store、路由、五个页面
```

## 数据导出

- **CSV**（损伤标注页）：UTF-8 BOM，Excel 直接打开，含测量值、限度、判定、反算残差与世界坐标。
- **JSON 数据包**（复查对比页）：构型+探头+记录+标注全量，带格式版本号，可在另一台浏览器导入合并。

## 设计边界（演示系统）

- 叶型为参数化工程近似（非真实型号实测叶型），AMM 限度数值为演示占位，接入真实数据时替换 `Stage.ammLimits` 与叶型参数即可，数学管线不变。
- 碰撞检测的导向器干涉用六点短射线近似，工程精度满足路径规划演示；若需毫米级间隙分析可加密采样方向。
